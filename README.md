# TensileTest — ПЗ для розривної (випробувальної) машини

Програмне забезпечення на базі **Qt 5 (C++)** для автоматизованого керування, збору даних, побудови графіків розтягу/деформації та аналізу міцності матеріалів на випробувальній (розривній) машині.

---

## 1. Апаратний комплекс (Hardware)

Система працює у зв'язці з таким обладнанням:

### 1.1. Тензометричні датчики (Load Cells)
У системі передбачено використання трьох змінних тензодатчиків виробництва **OAP / Keli** залежно від діапазону випробувальних зусиль:
* **DEF 50 kg (OAP quality)** — для випробувань на малі навантаження (до ~490 Н): полімерні плівки, гума, текстиль, нитки, тонкий дріт.
* **DEF 500 kg (OAP quality)** — для середніх навантажень (до ~4.9 кН): пластмаси, композити, шнури, тонкі металеві смуги.
* **PST-3t (OAP quality)** — S-подібний тензодатчик на розтяг/стиск на 3 тонни (до ~29.4 кН): метали, арматура, троси, міцні конструкційні матеріали.

### 1.2. Ваговий індикатор (ваговий термінал)
* **ХК 3118 Т16 (Keli XK3118-T16)**
  * Призначення: перетворення сигналу з тензомоста в цифрове значення ваги.
  * Інтерфейс: **RS-232 / COM-порт**.
  * Параметри зв'язку: `9600 baud, 8 data bits, 1 stop bit, No parity (8N1)`.
  * Режим роботи: неперервна передача даних (Continuous ASCII stream).

### 1.3. Датчик переміщення / видовження траверси (Length)
* Цифровий вимірювач переміщення / датчик лінійних переміщень.
* Інтерфейс: **COM-порт (RS-232 / USB-UART)**.

### 1.4. Частотний перетворювач (Frequency Inverter / VFD)
* **Delta VFD** (серії VFD-M, VFD-EL, VFD-E або сумісні)
  * Призначення: плавне керування асинхронним електродвигуном приводу рухомої траверси (напрямок «Вгору / Вниз», швидкість переміщення через завдання вихідної частоти).
  * Інтерфейс: **RS-485 (через USB-RS485 перетворювач)**.
  * Протокол: **Modbus ASCII**.
  * Параметри зв'язку: `9600 baud, 7 data bits, 2 stop bits, No parity (7N2)` (або `7E1`).
  * Керуючі регістри:
    * `2000H` — команда керування приводом (`0001H` — Стоп, `0002H` — Пуск, `0010H` — Вперед/Вгору, `0020H` — Назад/Вниз).
    * `2001H` — завдання частоти (F = значення * 0.01 Гц).

```text
    ├── qcustomplot.h/.cpp    # Бібліотека побудови графіків QCustomPlot
    └── DataBase.db           # База даних SQLite
```

## 3. Поточний стан проєкту (Initial Baseline)

### 3.1. Що реалізовано
1. **Інтерфейс користувача (GUI)**:
   * Сканування доступних COM-портів у системі.
   * Окреме підключення для трьох каналів: **Force** (зусилля), **Length** (видовження), **Frequency** (Delta VFD).
   * Панель ручного керування приводом Delta VFD: кнопка "Вперед" (Forward), "Назад" (Reverse), "Стоп", встановлення частоти (в Гц).
   * Відображення поточного часу досліду, сили та переміщення на LCD-індикаторах.
2. **Збір даних та побудова графіка**:
   * Опитування за таймером 100 мс (10 Гц).
   * Побудова кривої $F(\Delta L)$ у реальному часі на полотні `QCustomPlot`.
   * Запис серій, геометрії зразка ($L, W, H$, матеріал) та результатів у базу даних SQLite.
   * Можливість завантаження та перегляду раніше збережених експериментів.

### 3.2. Виявлені недоліки та проблеми в поточному коді
* **Зчитування з індикатора XK 3118 T16**: рядок обрізається жорстким зрізом `mid(1, 7)` за таймером без перевірки наявності цілого кадру. Немає обробки сигналу `readyRead`. Немає кнопки тарування (Zero).
* **Поріг запуску**: у коді зашито умову `if (f > 5)`. Для датчика DEF 50 kg це становить 10% шкали і призводить до втрати даних на малих навантаженнях.
* **Масштабування одиниць**: значення зберігаються у кілограмах/умовних одиницях, відсутній вибір встановленого тензодатчика та перерахунок у Ньютони ($1\text{ кг} \approx 9.80665\text{ Н}$).
* **LRC для Delta VFD**: функція `lrcCount` у `vfd2.cpp` має помилку переповнення при сумі байтів > 256, а також формує некоректний ASCII-кадр, якщо байт контрольної суми менший за `0x10` (відсутній лідируючий нуль).
* **Потоки та БД**: опитування COM-портів, розрахунки та поодинокі `INSERT` до SQLite виконуються у головному GUI-потоці без транзакцій, що викликає мікрофрізи інтерфейсу.

## 4. Вимоги до оточення та збірка

- **ОС**: Windows 10 / 11 (64-bit)
- **Фреймворк**: Qt 5.15.2 (MinGW 64-bit)
- **Модулі Qt**: `core`, `gui`, `widgets`, `serialport`, `sql`, `printsupport`
- **Складання**:
  1. Відкрити проєкт `TensileTest/TensileTest.pro` у **Qt Creator**.
  2. Обрати комплект збірки (Kit): **Desktop Qt 5.15.2 MinGW 64-bit**.
  3. Зібрати проєкт (`Ctrl + B`) або запустити (`Ctrl + R`).
